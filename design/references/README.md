# References

Put 8 to 15 full-page phone screenshots here (390px wide). Not 60: past about fifteen the set
stops having a point of view and Claude averages it.

- Full screens, not crops. Spacing is the design.
- Name each by what you want from it: `03-home-balance-card.png`, `07-pin-keypad.png`.
- Include one you dislike, named `00-avoid-cluttered-wallet.png`.
- Mix kinds of apps. Fifteen wallets in a row average into one generic wallet.
- Sources: Mobbin (finance category), real apps on your phone (screenshot them), Dribbble.
  Study bKash, Nagad and others for flows. Do not copy their branding.

## Screens worth collecting references for

1. Login (phone + PIN, "Try demo" buttons)
2. Registration wizard: step progress, phone/OTP, NID entry, camera or gallery photo picker
3. Home: balance card (tap to reveal), action grid, recent transactions, bottom nav
4. Amount entry with keypad
5. Preview step: amount, fee, total, recipient
6. PIN entry
7. Success receipt (TrxID, parties, fee, balance after)
8. Transaction history with filters
9. KYC "under review" screen
10. Empty, loading and error states

Images in this folder are git-ignored (see `.gitignore` next to this file) so you do not publish
other companies' screenshots in a public repo. Delete that file if you want them committed.
`*-DESIGN.md` rule files you generate here are committed.
